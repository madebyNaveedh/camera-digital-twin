\section{System Overview}
This project implements a real-time digital twin connecting a desktop camera to the \textbf{CoppeliaSim} robotics simulator. A physical camera observes a defined desk working area and tracks either a printed ArUco marker or a colored object (Red, Green, Blue). The extracted 2D pixel coordinates are mapped onto a $3.0\text{m} \times 3.0\text{m}$ virtual arena, updating a simulated obstacle position in real time. Inside the virtual environment, a \textbf{Pioneer P3DX} mobile robot autonomously patrols a perimeter path and halts safely whenever the obstacle is moved into its forward route.

The pipeline operates in real time at \textbf{30 FPS} through four connected steps:
\begin{enumerate}
    \item \textbf{Video Capture:} Captures $640\times480$ RGB frames from a standard USB webcam using OpenCV.
    \item \textbf{Object Tracking:} Extracts the physical object centroid $(u, v)$ in image space.
    \item \textbf{Coordinate Mapping:} Normalizes pixel coordinates to arena coordinates $(X_{\text{sim}}, Y_{\text{sim}})$ with jitter smoothing.
    \item \textbf{Simulation Interface:} Synchronises obstacle position and reads Pioneer robot telemetry via the ZeroMQ API.
\end{enumerate}

\section{Physical Object Tracking}
The vision module provides two reliable tracking modes without requiring heavy deep-learning dependencies:
\begin{itemize}
    \item \textbf{ArUco Marker Tracking:} Detects standard \texttt{DICT\_4X4\_50} fiducial markers. The detector resolves marker corner coordinates and computes the center point $(c_u, c_v)$. This provides robust, flicker-free tracking across varying room illumination.
    \item \textbf{HSV Color Tracking:} Implements color segmentation with calibrated presets for common colored markers:
    \begin{itemize}
        \item \textbf{Blue Preset [Key 1]:} $H \in [100, 135]$, $S \in [100, 255]$, $V \in [60, 255]$
        \item \textbf{Green Preset [Key 2]:} $H \in [35, 85]$, $S \in [70, 255]$, $V \in [50, 255]$
        \item \textbf{Red Preset [Key 3]:} Handles hue wraparound ($H \in [0, 10] \cup [168, 180]$, $S \in [100, 255]$, $V \in [70, 255]$)
    \end{itemize}
    Noise is cleaned using morphological opening and closing with a $5\times5$ kernel. The object center is calculated from spatial moments ($c_u = M_{10}/M_{00},\; c_v = M_{01}/M_{00}$).
\end{itemize}

\section{Desk-to-Arena Coordinate Transformation}
A region of interest (ROI) on the camera view defines the active desk workspace:
\begin{equation}
    u \in [u_{\text{min}}, u_{\text{max}}] = [100, 540]\text{ px}, \quad v \in [v_{\text{min}}, v_{\text{max}}] = [60, 420]\text{ px}
\end{equation}
Coordinates are normalized to $\bar{u}, \bar{v} \in [-1.0, 1.0]$ and scaled linearly to virtual arena coordinates $(X_{\text{sim}}, Y_{\text{sim}}) \in [-1.4\text{m}, +1.4\text{m}]$. Hand jitter during physical object movement is smoothed using an Exponential Moving Average (EMA) filter:
\begin{equation}
    \mathbf{p}_{\text{smooth}}[t] = \alpha \cdot \mathbf{p}_{\text{raw}}[t] + (1 - \alpha) \cdot \mathbf{p}_{\text{smooth}}[t-1], \quad \alpha = 0.70
\end{equation}
If the object is removed from the camera view, the system maintains its last known position for $2.0\text{ seconds}$ before hiding the obstacle, preventing abrupt jump artifacts in the simulation.

\section{CoppeliaSim Environment \& Robot Navigation}
The virtual room is modelled in \textbf{CoppeliaSim Edu 4.10} as an open $3.0\text{m} \times 3.0\text{m}$ square box arena with $0.45\text{m}$ wall heights. The lowered wall height ensures full visibility of the robot, path, and obstacle from an overhead isometric perspective.

\subsection{Perimeter Waypoint Following}
The differential-drive \textbf{Pioneer P3DX} mobile robot navigates a continuous square perimeter route around the arena across four corner waypoints:
\begin{equation}
    \mathbf{W}_0 (+0.95, -0.95) \longrightarrow \mathbf{W}_1 (+0.95, +0.95) \longrightarrow \mathbf{W}_2 (-0.95, +0.95) \longrightarrow \mathbf{W}_3 (-0.95, -0.95)
\end{equation}
\begin{itemize}
    \item \textbf{Straight Navigation:} The robot drives toward the active waypoint at linear velocity $v = 0.16\text{ m/s}$ with proportional yaw correction ($k_p = 0.85$) to keep heading aligned.
    \item \textbf{In-Place Corner Turning:} When the robot reaches within $0.16\text{m}$ of a corner waypoint, it stops linear motion ($v = 0.0\text{ m/s}$) and turns in place ($\omega = 0.60\text{ rad/s}$) until oriented toward the next waypoint. This prevents wide turns that could bring the robot into contact with boundary walls.
\end{itemize}

\subsection{Obstacle Detection \& Safety Halting}
The robot monitors the physical obstacle's digital twin position relative to its current pose:
\begin{enumerate}
    \item \textbf{Forward Cone Safety Check:} The controller calculates the distance and heading angle to the virtual obstacle. If the obstacle is within $0.65\text{m}$ and inside a forward heading cone of $\pm 50^\circ$, wheel velocities are set to zero (\texttt{OBSTACLE BLOCKING PATH}). When the physical object is moved away, the robot resumes its perimeter route.
    \item \textbf{Front Ultrasonic Clearance:} Readings from the robot's front ultrasonic sensors (indices 2 through 5) are polled in real time. If an object is detected closer than $0.18\text{m}$, the robot halts as a safety safeguard.
    \item \textbf{State Recovery:} If the robot tilts or leaves the floor boundary ($Z < 0.05\text{m}$), the interface automatically resets its position safely to waypoint $\mathbf{W}_0$.
\end{enumerate}

\section{Conclusion}
This system demonstrates a practical physical-to-virtual digital twin. By linking real-time computer vision with simulated mobile robotics, physical objects moved on a desk surface dynamically control virtual obstacles in CoppeliaSim, enabling the Pioneer P3DX mobile robot to interact with and respond safely to real-world physical placement.
